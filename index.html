자바 기본 문법

01프로그램 구조와 출력

자바 코드는 반드시 클래스 안에 있고, 프로그램은 main 메서드부터 실행됩니다. 파일 이름은 public class 이름과 같아야 합니다(Main.java).

public class Main {                        // 클래스 이름 = 파일 이름
    public static void main(String[] args) { // 실행 시작점
        System.out.println("안녕, 자바");     // 출력 후 줄바꿈
        System.out.print("줄바꿈 ");          // 줄바꿈 없음
        System.out.print("없음\n");           // \n 직접 넣기

        String name = "kim";
        int age = 25;
        System.out.println("이름: " + name + ", 나이: " + age);  // + 로 이어붙이기
        System.out.printf("이름: %s, 나이: %d%n", name, age);   // 형식 지정 출력
        System.out.printf("소수 둘째 자리: %.2f%n", 3.14159);    // 3.14
    }
}

04형변환

작은 타입 → 큰 타입은 자동으로 바뀌고, 큰 타입 → 작은 타입은 (타입)을 붙여 직접 바꿔야 합니다. 문자열과 숫자 사이는 메서드로 바꿉니다.

// 숫자끼리
int n = 10;
double d = n;              // 자동: 10.0
int cut = (int) 3.99;      // 강제: 3 (반올림 아님, 버림)
double avg = (double) 7 / 2;  // 3.5 (나누기 전에 바꿔야 함)

// 문자 ↔ 숫자
char c = 'A';
int code = c;              // 65 (유니코드 값)
char next = (char) (c + 1);   // 'B'
int digit = '7' - '0';     // 7 (숫자 문자 → 정수, 코테 단골)

// 문자열 → 숫자
int x = Integer.parseInt("123");
double y = Double.parseDouble("3.14");
long z = Long.parseLong("10000000000");

// 숫자 → 문자열
String s1 = String.valueOf(123);   // "123"
String s2 = 123 + "";              // "123" (간단하지만 덜 명확)
String s3 = Integer.toString(123); // "123"

예외 주의 · Integer.parseInt("12a")처럼 숫자가 아닌 문자열을 넣으면 NumberFormatException이 발생합니다.

08메서드

반복되는 코드를 이름 붙여 묶은 것입니다. [접근제어자] [static] 반환타입 이름(매개변수) 모양입니다. 돌려줄 값이 없으면 반환 타입은 void입니다.

public class Main {

    // 두 수를 받아 합을 돌려줌
    static int add(int a, int b) {
        return a + b;
    }

    // 돌려줄 값이 없음
    static void greet(String name) {
        System.out.println("안녕, " + name);
    }

    // 오버로딩: 이름이 같아도 매개변수가 다르면 OK
    static double add(double a, double b) {
        return a + b;
    }

    // 가변 인자: 개수 상관없이 받기
    static int sumAll(int... nums) {
        int s = 0;
        for (int n : nums) s += n;
        return s;
    }

    public static void main(String[] args) {
        int r = add(3, 4);          // 7
        greet("kim");
        double d = add(1.5, 2.5);   // 4.0
        int all = sumAll(1, 2, 3, 4);  // 10
    }
}

static이 붙은 이유 · main이 static이라 같은 클래스의 메서드를 객체 없이 바로 부르려면 static이어야 합니다. 클래스와 객체를 배우면(블록 2) static 없는 메서드를 객체.메서드()로 부르게 됩니다.

01Scanner java.util.Scanner · 키보드 입력

콘솔에서 사용자 입력을 받을 때 씁니다. System.in(키보드)을 넣어서 객체를 만듭니다.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("이름: ");
        String name = sc.next();        // 공백 전까지 한 단어

        System.out.print("나이: ");
        int age = sc.nextInt();         // 정수

        System.out.print("키: ");
        double height = sc.nextDouble(); // 실수

        sc.nextLine();                  // ← 남은 엔터 비우기 (아래 설명)

        System.out.print("자기소개: ");
        String intro = sc.nextLine();   // 공백 포함 한 줄 전체

        System.out.printf("%s(%d세, %.1fcm): %s%n", name, age, height, intro);
        sc.close();
    }
}
메서드읽는 것입력 → 결과
nextInt()정수 하나42 → 42
nextLong() / nextDouble()큰 정수 / 실수3.5 → 3.5
next()공백·엔터 전까지 한 단어hong gildong → "hong"
nextLine()엔터 전까지 한 줄 전체hong gildong → "hong gildong"
nextBoolean()true/falsetrue → true
hasNextInt()다음이 정수인지 확인잘못된 입력 거르기
hasNext()입력이 남았는지입력 끝까지 읽을 때

nextInt 다음 nextLine 함정 · nextInt()는 숫자만 가져가고 엔터(\n)를 남겨둡니다. 그 다음 nextLine()은 남은 엔터를 읽고 바로 빈 문자열을 돌려줍니다. 그래서 숫자 입력 뒤 한 줄을 받으려면 위 예제처럼 sc.nextLine();을 한 번 더 호출해 버퍼를 비웁니다.

02BufferedReader 빠른 입력 · 코딩테스트용

입력이 수만 줄 이상이면 Scanner가 느려서 시간 초과가 납니다. 이때는 줄 단위로 빠르게 읽는 BufferedReader를 씁니다. 항상 문자열로 읽으므로 숫자는 직접 변환합니다.

import java.io.*;
import java.util.*;

public class Main {
    public static void main(String[] args) throws IOException {  // throws 필수
        BufferedReader br = new BufferedReader(new InputStreamReader(System.in));

        int n = Integer.parseInt(br.readLine());          // 한 줄 → 정수

        StringTokenizer st = new StringTokenizer(br.readLine());  // "10 20 30" 공백으로 쪼개기
        int[] arr = new int[n];
        for (int i = 0; i < n; i++) {
            arr[i] = Integer.parseInt(st.nextToken());
        }

        // split 으로도 가능
        String[] parts = br.readLine().split(" ");

        // 출력도 많으면 StringBuilder에 모아서 한 번에
        StringBuilder sb = new StringBuilder();
        for (int x : arr) sb.append(x).append('\n');
        System.out.print(sb);
    }
}

package com.example.hello.repository;

import com.example.hello.domain.Member;
import org.springframework.stereotype.Repository;
import java.util.*;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.atomic.AtomicLong;

@Repository   // Spring이 이 객체를 만들어 관리(빈 등록)
public class MemoryMemberRepository implements MemberRepository {

    private final Map<Long, Member> store = new ConcurrentHashMap<>();
    private final AtomicLong sequence = new AtomicLong();

    @Override
    public Member save(Member member) {
        member.setId(sequence.incrementAndGet());
        store.put(member.getId(), member);
        return member;
    }

    @Override
    public Optional<Member> findById(Long id) {
        return Optional.ofNullable(store.get(id));
    }

    @Override
    public Optional<Member> findByName(String name) {
        return store.values().stream()
                .filter(m -> m.getName().equals(name))
                .findFirst();
    }

    @Override
    public List<Member> findAll() {
        return new ArrayList<>(store.values());
    }
}
service/MemberService.java 규칙은 여기에만
package com.example.hello.service;

import com.example.hello.domain.Member;
import com.example.hello.repository.MemberRepository;
import org.springframework.stereotype.Service;
import java.util.List;

@Service
public class MemberService {

    private final MemberRepository memberRepository;

    // 생성자가 하나면 Spring이 알아서 MemoryMemberRepository를 넣어줌 (DI)
    public MemberService(MemberRepository memberRepository) {
        this.memberRepository = memberRepository;
    }

    public Long join(String name) {
        memberRepository.findByName(name).ifPresent(m -> {
            throw new IllegalStateException("이미 존재하는 회원입니다.");
        });
        return memberRepository.save(new Member(name)).getId();
    }

    public Member findOne(Long id) {
        return memberRepository.findById(id)
                .orElseThrow(() -> new IllegalArgumentException("회원이 없습니다. id=" + id));
    }

    public List<Member> findAll() {
        return memberRepository.findAll();
    }
}

controller/MemberController.java URL과 Service를 연결
package com.example.hello.controller;

import com.example.hello.dto.MemberCreateRequest;
import com.example.hello.dto.MemberResponse;
import com.example.hello.service.MemberService;
import org.springframework.web.bind.annotation.*;
import java.util.List;

@RestController                  // 반환값을 JSON으로 응답
@RequestMapping("/api/members")   // 이 클래스의 공통 URL
public class MemberController {

    private final MemberService memberService;

    public MemberController(MemberService memberService) {
        this.memberService = memberService;
    }

    @PostMapping                     // POST /api/members
    public MemberResponse create(@RequestBody MemberCreateRequest request) {
        Long id = memberService.join(request.name());
        return MemberResponse.from(memberService.findOne(id));
    }

    @GetMapping                      // GET /api/members
    public List<MemberResponse> list() {
        return memberService.findAll().stream()
                .map(MemberResponse::from)
                .toList();
    }

    @GetMapping("/{id}")            // GET /api/members/1
    public MemberResponse get(@PathVariable Long id) {
        return MemberResponse.from(memberService.findOne(id));
    }
}
exception/GlobalExceptionHandler.java 예외를 500 대신 400 + 메시지로
package com.example.hello.exception;

import org.springframework.http.HttpStatus;
import org.springframework.web.bind.annotation.*;
import java.util.Map;

@RestControllerAdvice
public class GlobalExceptionHandler {

    @ResponseStatus(HttpStatus.BAD_REQUEST)
    @ExceptionHandler({IllegalStateException.class, IllegalArgumentException.class})
    public Map<String, String> handle(RuntimeException e) {
        return Map.of("message", e.getMessage());
    }
}
